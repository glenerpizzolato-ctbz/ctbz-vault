# PRD-174490 — Guias do agrupamento no detalhe do envio (Agrupamento de Guias)

- **Épico:** [[PRD-165450]] — [2026-QD3] CTS - Eng Canais
- **Situação:** pronto · **Tipo:** melhoria · **Atuação:** BE, FE
- **Período:** 2026QD3 · **Domínio:** impostos, notificacoes
- **Jira:** https://contabilizeicontabilidade.atlassian.net/browse/PRD-174490

## Contexto

No dashboard Agrupamento de Guias do `atendimento-canais-admin` (`/notificacoes/dashboards/agrupamento-guias`), o modal de detalhe (olhinho na aba "lista") mostra só o id do `grupo_guia`. Cada envio aponta para um `grupo_guia_id` (pacote mensal) ou para um `controle_guia_id` (guia avulsa), nunca os dois. A ligação grupo → guias fica em `item_grupo_guia` do `microsservico-agrupamento-guias`; o admin lê do BigQuery (`contabilizei-dataflow.dw_ms_agrupamento_guias`), que ainda não é consultado para essa tabela.

Entrega: rota `GET /api/notificacoes/controle-notificacao/grupos/:grupoId/guias` (com `denyUnlessFeatureAccess`) e seção "Guias do agrupamento" no modal, com loading/vazio/erro, oculta para guia avulsa; 100% de cobertura e rota na coleção Bruno.
